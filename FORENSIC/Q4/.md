--------------------------------2. Run `strings "OBSERVE THE OBSERVER.zip"` — a garbled, non-printable-looking blob sits right after the filename in the output. It is not readable text, so a naive strings pass doesn't reveal the flag directly.

This blob is data stored in the ZIP local file header's "extra field" (a legitimate ZIP-spec area for custom metadata, tagged with an unrecognized header ID so all standard tools skip it silently). --------------------------------4. The payload is the flag encrypted with a single-byte XOR key. Brute-force all 256 possible key values against the payload and check for a result starting with "CyC0g{" — this is the standard single-byte XOR cracking technique.

--------------------------------5. Key 0x5A recovers the flag.
