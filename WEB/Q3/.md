--------------------------------4. Decode on jwt.io or manually → spot "score": <your_score>
--------------------------------5. Change "score" to 99999 in the payload
--------------------------------6. Re-encode the payload (base64url)
--------------------------------7. Keep the same header and signature — server doesn't verify it
--------------------------------8. Set the forged token in console:
